Mental Model — The Sliding Window

A window function looks at a 'window' of rows around each row. PARTITION BY slices the data; ORDER BY arranges rows within each slice; frame clauses (ROWS/RANGE) define the window boundaries.

Think of a spreadsheet: each row gets a new column computed from its 'window' of peer rows. PARTITION BY = filter to same department. ORDER BY = sort by salary. The function then computes over that window.

  • Window functions ONLY in SELECT and ORDER BY clauses
  • PARTITION BY = grouping without collapsing
  • ORDER BY in OVER = defines row sequence for ranking/frame
  • Default frame: RANGE UNBOUNDED PRECEDING TO CURRENT ROW

Ranking Functions — ROW_NUMBER, RANK, DENSE_RANK

ROW_NUMBER — Unique Sequential

row_number
-- Number rows within each department by salary desc
SELECT 
  name,
  dept_id,
  salary,
  ROW_NUMBER() OVER (PARTITION BY dept_id ORDER BY salary DESC) AS rn
FROM employees;

-- Top 3 per department
SELECT * FROM (
  SELECT *, ROW_NUMBER() OVER (PARTITION BY dept_id ORDER BY salary DESC) AS rn
  FROM employees
) t WHERE rn <= 3;

Navigation Functions — LAG, LEAD, FIRST_VALUE, LAST_VALUE

LAG / LEAD — Look Behind / Ahead

lag lead
-- LAG: previous row's value
SELECT 
  sale_date,
  amount,
  LAG(amount) OVER (ORDER BY sale_date) AS prev_amount,
  LAG(amount, 2) OVER (ORDER BY sale_date) AS two_days_ago
FROM daily_sales;

-- LEAD: next row's value
SELECT 
  sale_date,
  amount,
  LEAD(amount) OVER (ORDER BY sale_date) AS next_amount
FROM daily_sales;

-- With default value
SELECT 
  sale_date,
  amount,
  LAG(amount, 1, 0) OVER (ORDER BY sale_date) AS prev_amount
FROM daily_sales;

FIRST_VALUE / LAST_VALUE — Frame Boundaries

first_value last_value
-- FIRST_VALUE: first in window
SELECT 
  dept_id,
  name,
  salary,
  FIRST_VALUE(salary) OVER (PARTITION BY dept_id ORDER BY salary DESC) AS dept_max
FROM employees;

-- LAST_VALUE needs explicit frame!
SELECT 
  dept_id,
  name,
  salary,
  LAST_VALUE(salary) OVER (
    PARTITION BY dept_id ORDER BY salary DESC
    ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING
  ) AS dept_min
FROM employees;

Glossary

window functionComputes value per row using a window of rows defined by OVER clause.
PARTITION BYDivides result into partitions; function computed independently per partition.
frame clauseROWS/RANGE BETWEEN ... defines window boundaries relative to current row.
ROW_NUMBERUnique sequential number per partition.
RANKRank with gaps on ties (1,2,2,4).
DENSE_RANKRank without gaps on ties (1,2,2,3).
