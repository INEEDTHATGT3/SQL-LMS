Mental Model — Analytics Beyond GROUP BY

GROUP BY collapses rows. Advanced analytics keeps rows but adds computed columns: PIVOT for cross-tabs, LATERAL for per-row subqueries, advanced frames for moving analytics, sampling for big data.
  • GROUP BY reduces rows; advanced analytics adds columns without collapsing
  • PIVOT/crosstab: row values become column headers (cross-tabulation)
  • LATERAL: correlated subquery in FROM clause — right side sees left columns
  • Frame clauses: ROWS/RANGE/GROUPS with PRECEDING/FOLLOWING/UNBOUNDED
  • Sampling: TABLESAMPLE for approximate queries on massive tables

PIVOT / Crosstab — Cross-Tabulation

PostgreSQL crosstab()

crosstab example
-- Enable extension
CREATE EXTENSION IF NOT EXISTS tablefunc;

-- Crosstab: row_header, category, value
SELECT * FROM crosstab(
  'SELECT dept, quarter, SUM(sales) FROM sales GROUP BY dept, quarter ORDER BY 1,2',
  'SELECT DISTINCT quarter FROM sales ORDER BY 1'
) AS ct(dept TEXT, q1 NUMERIC, q2 NUMERIC, q3 NUMERIC, q4 NUMERIC);

LATERAL JOIN — Correlated Subquery in FROM

lateral basics
-- For each employee, get latest order
SELECT e.name, o.order_date, o.total
FROM employees e
LEFT JOIN LATERAL (
  SELECT order_date, total
  FROM orders o
  WHERE o.emp_id = e.id
  ORDER BY o.order_date DESC
  LIMIT 1
) o ON true;

-- Equivalent correlated subquery (harder to read)
SELECT e.name,
  (SELECT order_date FROM orders o WHERE o.emp_id = e.id ORDER BY order_date DESC LIMIT 1) AS latest_date,
  (SELECT total FROM orders o WHERE o.emp_id = e.id ORDER BY order_date DESC LIMIT 1) AS latest_total
FROM employees e;

Advanced Frames — ROWS/RANGE/GROUPS, EXCLUDE

Frame Clauses Deep Dive

frame syntax
-- ROWS: physical row count
SUM(amount) OVER (
  ORDER BY sale_date
  ROWS BETWEEN 3 PRECEDING AND CURRENT ROW
) AS moving_sum_4days

-- RANGE: value-based (ORDER BY must be numeric/date)
SUM(amount) OVER (
  ORDER BY sale_date
  RANGE BETWEEN INTERVAL '3 days' PRECEDING AND CURRENT ROW
) AS moving_sum_3days

-- Unbounded
SUM(amount) OVER (
  ORDER BY sale_date
  ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING
) AS total_so_far

RANGE INTERVAL '1 day' PRECEDING with ORDER BY ts includes:
AExactly 1 row before
BAll rows where ts >= current_ts - 1 day
CCurrent row only
DError
RANGE uses value semantics. All rows with ts within 1 day of current row's ts.
ROWS 1 PRECEDING vs RANGE 1 PRECEDING with ORDER BY salary:
ASame
BROWS = 1 row before; RANGE = salaries within 1 of current
CRANGE = 1 row; ROWS = salary ± 1
DBoth invalid
ROWS counts rows. RANGE uses ORDER BY value difference (salary ± 1).

NTILE, Sampling, Advanced Aggregates

NTILE(n) — Equal-Size Buckets

ntile
-- Quartiles (4 buckets)
SELECT 
  name,
  salary,
  NTILE(4) OVER (ORDER BY salary) AS quartile
FROM employees;

-- Deciles (10 buckets)
SELECT 
  name,
  salary,
  NTILE(10) OVER (ORDER BY salary) AS decile
FROM employees;

-- Per department
SELECT 
  dept_id,
  name,
  salary,
  NTILE(4) OVER (PARTITION BY dept_id ORDER BY salary) AS dept_quartile
FROM employees;

NTILE distributes rows as evenly as possible. If rows % n ≠ 0, first buckets get 1 extra row. NTILE(4) on 10 rows → buckets: 3,3,2,2 rows.

TABLESAMPLE — Fast Approximate Queries

tablesample
-- SYSTEM: page-level sampling
SELECT * FROM large_table TABLESAMPLE SYSTEM (10);
-- ~10% of pages

-- BERNOULLI: row-level sampling
SELECT * FROM large_table TABLESAMPLE BERNOULLI (10);
-- True 10% of rows, slower

-- Repeatable (deterministic)
SELECT * FROM large_table TABLESAMPLE SYSTEM (10) REPEATABLE (42);

Advanced Aggregates — FILTER, Percentile, Approximate

filter clause / percentile
-- FILTER: conditional aggregate in one scan
SELECT dept_id,
  COUNT(*) FILTER (WHERE status = 'active') AS active_cnt,
  COUNT(*) FILTER (WHERE status = 'pending') AS pending_cnt
FROM employees
GROUP BY dept_id;

-- Percentile aggregates
SELECT 
  percentile_cont(0.5) WITHIN GROUP (ORDER BY salary) AS median,
  percentile_disc(0.5) WITHIN GROUP (ORDER BY salary) AS median_discrete
FROM employees;

-- With GROUP BY
SELECT dept_id,
  percentile_cont(0.5) WITHIN GROUP (ORDER BY salary) AS median_sal
FROM employees
GROUP BY dept_id;
