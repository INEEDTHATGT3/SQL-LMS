Mental Model — The Collapsing Funnel

GROUP BY is a funnel: many rows enter, they're sorted by key, identical keys merge into one row. Aggregates (COUNT, SUM, AVG) compute on each bucket.
  • Every non-aggregate column in SELECT must be in GROUP BY
  • NULLs group together (all NULLs = one group)
  • Aggregate functions: COUNT, SUM, AVG, MIN, MAX, STRING_AGG
  • ORDER BY runs after GROUP BY — can use aliases

Core Aggregates — COUNT, SUM, AVG, MIN, MAX

The Big Five

basic aggregates
-- COUNT: row count (includes NULL rows)
SELECT COUNT(*) FROM employees;
-- COUNT(col): non-NULL count
SELECT COUNT(manager_id) FROM employees;

-- SUM, AVG: numeric only
SELECT SUM(salary), AVG(salary) FROM employees;

-- MIN, MAX: any comparable type
SELECT MIN(hire_date), MAX(hire_date) FROM employees;

-- Multiple aggregates at once
SELECT dept_id,
  COUNT(*) AS emp_count,
  SUM(salary) AS total_pay,
  AVG(salary) AS avg_pay,
  MIN(salary) AS min_pay,
  MAX(salary) AS max_pay
FROM employees
GROUP BY dept_id;

-- STRING_AGG for concatenation
SELECT dept_id, STRING_AGG(name, ', ') FROM employees GROUP BY dept_id;
-- GROUP_CONCAT for concatenation
SELECT dept_id, GROUP_CONCAT(name SEPARATOR ', ') FROM employees GROUP BY dept_id;

GROUP BY — Multiple Columns, Expressions

Multi-Column Grouping

group by multiple
-- Group by dept AND status
SELECT dept_id, status, COUNT(*)
FROM employees
GROUP BY dept_id, status;
-- One row per (dept_id, status) combination

-- Group by expression
SELECT EXTRACT(YEAR FROM hire_date) AS yr, COUNT(*)
FROM employees
GROUP BY EXTRACT(YEAR FROM hire_date);
# Python version pending — add after validation.
-- GROUP BY can use expressions
SELECT date_trunc('month', created_at) AS month, COUNT(*)
FROM events
GROUP BY date_trunc('month', created_at);
-- Same syntax
SELECT YEAR(hire_date) AS yr, COUNT(*) FROM employees GROUP BY YEAR(hire_date);

HAVING — Filter Groups

having clause
-- Departments with > 10 employees
SELECT dept_id, COUNT(*) AS cnt
FROM employees
GROUP BY dept_id
HAVING COUNT(*) > 10;

-- HAVING can use aliases (PostgreSQL)
SELECT dept_id, COUNT(*) AS cnt
FROM employees
GROUP BY dept_id
HAVING cnt > 10;

-- Multiple HAVING conditions
SELECT dept_id, AVG(salary) AS avg_sal
FROM employees
GROUP BY dept_id
HAVING AVG(salary) > 50000 AND COUNT(*) > 5;
# Python version pending — add after validation.
-- Can use column alias in HAVING
SELECT dept_id, COUNT(*) AS cnt FROM employees GROUP BY dept_id HAVING cnt > 10;
-- MySQL: alias in HAVING works
SELECT dept_id, COUNT(*) AS cnt FROM employees GROUP BY dept_id HAVING cnt > 10;

RE-READ BEFORE ANY INTERVIEW / CONTEST

  • COUNT(*) = all rows; COUNT(col) = non-NULL only
  • SUM, AVG, MIN, MAX ignore NULLs
  • GROUP BY: non-aggregate columns in SELECT must appear in GROUP BY
  • WHERE = row filter (before GROUP BY); HAVING = group filter (after GROUP BY)
  • GROUP BY expressions allowed: EXTRACT(YEAR FROM date), dept_id + status
  • NULLs group together in GROUP BY

Glossary

aggregate functionComputes single value from multiple rows: COUNT, SUM, AVG, MIN, MAX.
GROUP BYCollapses rows with same key values into one row per group.
HAVINGFilters groups after aggregation (vs WHERE filters rows before).
bucketA group of rows with same GROUP BY key values.
aggregate expressionExpression containing aggregate function (e.g., COUNT(*) + 1).
null groupAll rows with NULL in GROUP BY column form one group together.
