Mental Model — The Subtotal Ladder

ROLLUP = hierarchical ladder (detail → subtotals → grand). CUBE = full cross-product (all combinations). GROUPING SETS = pick your own adventure. GROUPING() tells you which level you're on.
  • ROLLUP: N+1 levels (N columns + grand total)
  • CUBE: 2^N combinations
  • GROUPING SETS: explicit list, most flexible
  • GROUPING() + GROUPING_ID() distinguish detail vs subtotal rows

ROLLUP — Hierarchical Subtotals

ROLLUP Syntax & Behavior

rollup examples
-- Single column: detail + grand total
SELECT dept_id, COUNT(*)
FROM employees
GROUP BY ROLLUP(dept_id);
-- Result: 5 dept rows + 1 grand total (dept_id=NULL)

-- Two columns: detail + subtotals + grand
SELECT dept_id, status, COUNT(*)
FROM employees
GROUP BY ROLLUP(dept_id, status);
-- Hierarchy: (dept,status) → (dept) → ()

-- Partial rollup
SELECT dept_id, status, COUNT(*)
FROM employees
GROUP BY dept_id, ROLLUP(status);
-- Detail (dept,status) + (dept) subtotals + grand total

ASame
BFirst: (a,b) + (a) + (); Second: (a,b) + (a) + ()

DFirst includes (b) subtotal

CUBE — All Combinations

cube examples
-- Full cross-tab
SELECT dept_id, status, COUNT(*)
FROM employees
GROUP BY CUBE(dept_id, status);
-- Groups: (dept,status), (dept), (status), ()

GROUPING SETS ((a,b), (a)) produces groups:
A(a,b), (a), (b), ()
B(a,b), (a)
C(a,b), (a), ()
D(a,b), ()
Explicit list: (a,b) detail + (a) subtotal. Grand total () must be explicit.
CUBE(a,b) equivalent GROUPING SETS:
A((a,b), (a), ())
B((a,b), (a), (b), ())
C((a,b), (a), (b))
D((a), (b), ())
CUBE = all 2^N combinations. For 2 cols: (a,b), (a), (b), ().

GROUPING() & GROUPING_ID() — Label Your Subtotals

Identify Subtotal Rows

grouping functions
-- GROUPING(col): 1 if col is NULL due to rollup, 0 if detail
SELECT dept_id, status,
  GROUPING(dept_id) AS g_dept,
  GROUPING(status) AS g_status,
  COUNT(*)
FROM employees
GROUP BY ROLLUP(dept_id, status);

-- GROUPING_ID: bitmask of GROUPING() values
SELECT dept_id, status,
  GROUPING_ID(dept_id, status) AS gid,
  COUNT(*)
FROM employees
GROUP BY CUBE(dept_id, status);
-- gid: 0=detail, 1=status rolled, 2=dept rolled, 3=grand total

-- Pretty labels
SELECT 
  CASE WHEN GROUPING(dept_id)=1 THEN 'ALL DEPTS' ELSE dept_id END AS dept,
  CASE WHEN GROUPING(status)=1 THEN 'ALL STATUS' ELSE status END AS status,
  COUNT(*)
FROM employees
GROUP BY ROLLUP(dept_id, status);

GROUPING(dept_id) = 1 means:
Adept_id is NULL in source data
BRow is subtotal where dept_id was rolled up
Cdept_id = 1
DError
GROUPING(col) = 1 when col is NULL because it was rolled up (subtotal/grand total).
GROUPING_ID(dept, status) = 3 (binary 11) means:
ADetail row
Bdept subtotal
Cstatus subtotal
DGrand total (both rolled)
Bit 0 = status rolled, Bit 1 = dept rolled. 11 = both = grand total.
