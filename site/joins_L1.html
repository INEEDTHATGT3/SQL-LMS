Mental Model — The Venn Diagram

A JOIN connects two tables on a common column. Think Venn diagrams: INNER = intersection, LEFT = left circle + overlap, FULL = both circles.

Every row in employees has a dept_id pointing to departments. JOIN follows that pointer to bring department info into the employee row. It's like looking up a phone number in a directory.

  • Primary key (PK) = unique identifier in parent table (departments.id)
  • Foreign key (FK) = pointer in child table (employees.dept_id)
  • JOIN condition = FK = PK
  • One department → many employees (one-to-many)

Set Operations — UNION, INTERSECT, EXCEPT

Set Theory in SQL

union / intersect / except
-- UNION: all distinct rows from both
SELECT name FROM employees
UNION
SELECT name FROM contractors;
-- Removes duplicates

-- UNION ALL: all rows, keep duplicates
SELECT name FROM employees
UNION ALL
SELECT name FROM contractors;
-- Faster, no dedup

-- INTERSECT: common rows
SELECT dept_id FROM employees
INTERSECT
SELECT id FROM departments;

-- EXCEPT: in first, not in second
SELECT dept_id FROM departments
EXCEPT
SELECT dept_id FROM employees;
-- Departments with NO employees

60-second revision card

RE-READ BEFORE ANY INTERVIEW / CONTEST

  • INNER = intersection; LEFT = all left + match; RIGHT = all right + match; FULL = both
  • LEFT JOIN + WHERE right.id IS NULL = anti-join (left rows with no match)
  • JOIN condition in ON, not WHERE (especially for LEFT — WHERE filters after join)
  • Self join = table aliases + FK to same table (manager_id → id)
  • UNION = distinct (slow); UNION ALL = all rows (fast); use ALL when possible
  • INTERSECT = common; EXCEPT = in first not second

Glossary

inner joinReturns only rows with matches in both tables (intersection).
left joinAll left rows; matched right rows or NULL (left circle + overlap).
right joinAll right rows; matched left rows or NULL (right circle + overlap).
full joinAll rows from both tables; NULLs where no match (union of circles).
self joinTable joined to itself using aliases; FK references same table PK.
anti-joinLEFT JOIN + WHERE right.key IS NULL — finds rows with no match.
