Mental Model — Tables as Grids

A table is a grid of named columns and numbered rows. Columns have types; rows are records. No hidden magic.

Think of a spreadsheet: each sheet = a table. Columns (A, B, C...) have headers and types. Rows (1, 2, 3...) hold data. SQL lets you query this grid declaratively — you say *what* you want, not *how* to scan it.

  • Columns = vertical: fixed name, type, position
  • Rows = horizontal: each row = one entity (employee, order, etc.)
  • No inherent row order — use ORDER BY to sort
  • NULL = missing/unknown value, not zero or empty string

Filtering Basics — WHERE

WHERE Clause

equality & comparison
-- Exact match
SELECT * FROM employees WHERE dept_id = 3;

-- Not equal
SELECT * FROM employees WHERE dept_id <> 3;
-- or: WHERE dept_id != 3;

-- Range
SELECT * FROM employees WHERE salary BETWEEN 50000 AND 80000;

-- Greater/less
SELECT * FROM employees WHERE hire_date > '2023-01-01';

-- Find NULL
SELECT * FROM employees WHERE manager_id IS NULL;

To find rows where manager_id is missing, use:
AWHERE manager_id = NULL
BWHERE manager_id IS NULL
CWHERE manager_id == NULL
DWHERE manager_id <> NULL
NULL is not a value — it's the absence of value. Use IS NULL / IS NOT NULL.
BETWEEN 10 AND 20 includes:
AValues >10 and <20
BValues ≥10 and ≤20
COnly 10 and 20
DValues ≥10 and <20
BETWEEN is inclusive on both ends. Equivalent to col >= 10 AND col <= 20.

Sorting & Limiting — ORDER BY, LIMIT

order by & limit
-- Sort ascending (default)
SELECT * FROM employees ORDER BY salary;

-- Sort descending
SELECT * FROM employees ORDER BY salary DESC;

-- Multi-column sort
SELECT * FROM employees ORDER BY dept_id, salary DESC;

-- Top 5 highest paid
SELECT * FROM employees ORDER BY salary DESC LIMIT 5;

-- Pagination: page 2, 10 per page
SELECT * FROM employees ORDER BY id LIMIT 10 OFFSET 10;

ORDER BY salary DESC LIMIT 3 returns:
A3 lowest salaries
B3 highest salaries
C3 random salaries
DError — need WHERE
DESC = descending (high to low). LIMIT 3 takes first 3 after sort.
To get page 3 with 20 rows per page (0-indexed):
ALIMIT 20 OFFSET 3
BLIMIT 20 OFFSET 40
CLIMIT 20 OFFSET 60
DLIMIT 3 OFFSET 20
Page 3 (0-indexed) = skip 2 pages × 20 = 40 rows. OFFSET 40 LIMIT 20.

60-second revision card

RE-READ BEFORE ANY INTERVIEW / CONTEST

  • Tables = grids: columns (typed, named) × rows (records)
  • SELECT column_list FROM table — * means all columns
  • WHERE filters rows: =, <>, <, >, BETWEEN, IS NULL
  • ORDER BY col [ASC|DESC] — sorts result; LIMIT n — caps rows
  • NULL ≠ 0 ≠ '' — use IS NULL / IS NOT NULL to test
  • String concat: ANSI ||, MySQL CONCAT(), Python +

Glossary

tableNamed collection of rows with same column structure.
columnVertical slice of a table; has name, type, position.
rowHorizontal record; one entity instance.
NULLMissing/unknown value; not equal to anything including itself.
predicateBoolean expression in WHERE clause that filters rows.
projectionSelecting a subset of columns (vertical filtering).
