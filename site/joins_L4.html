Dynamic Programming & GEQO — Join Ordering at Scale

DP Join Ordering (Default)

PostgreSQL uses Dynamic Programming for join ordering up to join_collapse_limit (default 8) or from_collapse_limit (default 8). DP considers all left-deep trees. Complexity O(3^N) — exponential but manageable for N ≤ 12.

dp vs geqo
-- DP join ordering (default for ≤ 12 joins)
SET join_collapse_limit = 8;  -- default
SET from_collapse_limit = 8;

-- GEQO (Genetic Query Optimizer) for > 12 joins
SET geqo_threshold = 12;  -- default
SET geqo = on;            -- default
SET geqo_effort = 5;      -- 1-10, higher = more search

-- Force GEQO off
SET geqo = off;
SET join_collapse_limit = 20;  -- extend DP
