Mental Model — Time as a Dimension

Time-series data adds a temporal dimension to your data — every observation has a 'when' alongside its 'what' and 'where'.

Think of time-series data as a movie rather than a photograph. Each frame has a timestamp, and the sequence reveals patterns — trends, cycles, anomalies — that a single snapshot cannot. Add location, and you get spatio-temporal data: a storm's path, a delivery truck's route, a disease outbreak's spread.

  • Time is ordered — observations have a natural sequence
  • Intervals can be regular (hourly) or irregular (event-driven)
  • Spatial data adds geometry: points, lines, polygons
  • Spatio-temporal = time-series + geometry per observation

-- Date truncation (granularity)

       COUNT(*)
FROM events
GROUP BY hour_bucket;

Coordinate Systems (SRID)

Every geometry has an SRID (Spatial Reference System Identifier). SRID 4326 = WGS 84 (GPS lat/lon). SRID 3857 = Web Mercator (web maps). Always set SRID for distance/area calculations to be meaningful.

setting & transforming SRID
-- Set SRID on geometry
SELECT ST_SetSRID(ST_MakePoint(-122.4, 37.7), 4326);

-- Transform to Web Mercator (meters)
SELECT ST_Transform(geom, 3857);

-- Distance in meters (requires projected CRS)
SELECT ST_Distance(
  ST_Transform(a.geom, 3857),
  ST_Transform(b.geom, 3857)
) FROM a, b;

Spatio-Temporal Queries — Time + Space

Moving Object Trajectories

trajectory as linestring
-- Build trajectory from point observations
SELECT vehicle_id,
       ST_MakeLine(geom ORDER BY ts) AS trajectory,
       MIN(ts) AS start_time,
       MAX(ts) AS end_time
FROM gps_points
WHERE vehicle_id = 'V123'
GROUP BY vehicle_id;

-- Segment trajectory by speed
SELECT ST_Segmentize(trajectory, 100) AS segmented
FROM trajectories;

Spatio-Temporal Joins

find events near a moving object
-- Find sensors within 1km of vehicle at each timestamp
SELECT s.sensor_id, v.vehicle_id, v.ts
FROM vehicles v
JOIN sensors s
  ON ST_DWithin(
    ST_Transform(v.geom, 3857),
    ST_Transform(s.geom, 3857),
    1000  -- 1km in meters (3857 = meters)
)
WHERE v.ts BETWEEN '2024-01-01' AND '2024-01-02';

-- Time-windowed spatial join
SELECT * FROM events e
JOIN sensors s
  ON ST_DWithin(e.geom, s.geom, 500)
 AND e.ts BETWEEN s.active_from AND s.active_to;

RE-READ BEFORE ANY INTERVIEW / CONTEST

  • TIMESTAMPTZ vs TIMESTAMP vs DATE — choose based on timezone needs
  • date_trunc('unit', ts) truncates to bucket boundary (hour, day, month)
  • generate_series creates regular time sequences; date_trunc buckets timestamps

  • date_trunc + GROUP BY = time bucketing; generate_series = gap filling
